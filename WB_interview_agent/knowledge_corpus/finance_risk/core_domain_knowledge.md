# 金融风控岗位核心知识（模板）

## 1. 风控全链路

- 贷前：准入、反欺诈、额度与定价
- 贷中：交易监控、行为预警、额度动态调整
- 贷后：催收分层、风险迁徙监控、资产处置

## 2. 数据与特征工程

- 多源数据接入：申请信息、设备指纹、行为日志、三方征信
- 特征治理：稳定性、可解释性、时间穿越防护
- 标签设计：逾期窗口、坏账定义、样本观察期

## 3. 模型与策略

- 评分卡与机器学习模型的分工
- 策略规则 + 模型融合（Champion/Challenger）
- 阈值分层：通过、人工复核、拒绝

## 4. 指标体系

- 分类效果：AUC、KS、PR-AUC
- 业务指标：通过率、坏账率、收益率、欺诈拦截率
- 稳定性：PSI、CSI、特征漂移监控

## 5. 合规与治理

- 可解释性与审计留痕
- 敏感特征与公平性约束
- 模型上线审批与回滚机制

## 6. 实时风控工程能力

- 规则引擎与特征服务低延迟设计
- 降级与容灾：特征缺失兜底、服务超时策略
- 监控告警：实时命中率、拦截率、延迟分位
