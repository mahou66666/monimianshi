# 计算机后端岗位核心技术栈（模板）

## 1. Java 与 JVM

- Java 内存模型（JMM）、可见性、有序性、原子性
- 垃圾回收器选型（G1/ZGC）与停顿优化
- 常见性能诊断手段：`jstack`、`jmap`、`arthas`、GC 日志分析

## 2. Spring Boot / 微服务

- 服务拆分边界：按业务域与数据所有权拆分
- 配置管理与灰度发布：版本兼容、回滚策略
- 限流/熔断/降级：网关与服务双层治理

## 3. MySQL

- 索引设计：联合索引最左匹配、覆盖索引、回表成本
- 事务与隔离级别：RR 下幻读处理、间隙锁
- 慢 SQL 优化：执行计划、统计信息、索引失效排查

## 4. Redis

- 缓存一致性：旁路缓存、延迟双删、订阅变更通知
- 大 Key / 热 Key 治理：拆分、限流、本地缓存兜底
- 穿透/击穿/雪崩防护：布隆过滤器、互斥锁、随机过期

## 5. 消息队列（Kafka/RocketMQ）

- 至少一次投递下的幂等消费
- 顺序性与分区设计
- 堆积治理与重试/死信策略

## 6. 分布式系统能力

- 一致性模型与 CAP 取舍
- 分布式事务（SAGA/TCC）适用场景
- 链路追踪与故障演练（可观测性）

## 7. 工程化与质量保障

- CI/CD 与质量门禁（测试覆盖率、静态扫描）
- 压测体系：容量规划、扩容阈值、SLO/SLA
- 安全基线：鉴权、越权防护、敏感数据脱敏
